# ⚡ Interactive Student Dashboard

## DecodeLabs – Frontend Development Project 3

An interactive frontend web project developed using **HTML, CSS, and JavaScript**.

The main purpose of this project is to demonstrate how JavaScript can be used to create interactive web elements, respond to user actions, manage state, and dynamically update the Document Object Model (DOM).

---

## 📌 Project Overview

This project is part of **DecodeLabs Industrial Training Kit – Frontend Development, Project 3**.

The objective of Project 3 is to add interactivity to a webpage using JavaScript.

The project demonstrates:

- Buttons and toggles
- Basic user interaction
- Dynamic content updates
- JavaScript event handling
- DOM manipulation
- State management
- Responsive design

The project follows the basic:

**Input → Process → Output**

model.

Example:

```text
User Action
     ↓
JavaScript Event
     ↓
JavaScript Logic
     ↓
DOM Update
     ↓
Visible Result
